# WCSController

`WCSController` 是一个 Spring REST 控制器，它似乎是一个未来或已弃用的 WCS（仓库控制系统）集成的存根或占位符。这些端点以创建仓库任务命名，但目前不包含任何业务逻辑。它们只是记录传入的请求并返回一个硬编码的成功响应。

**注意:** 此控制器的 `@Api` 标签是“道闸接口”，这似乎是一个复制粘贴错误，并不反映端点的功能。

## API 端点

### 1. 创建出库任务 (存根)

- **URL:** `/api/ReceWms/CreateOutTask`
- **HTTP 方法:** `POST`
- **描述:** 一个旨在创建出库任务的占位符端点。目前，它只将请求体记录到控制台。
- **请求体:**
  - `carMsg` (Map<String, Object>): 一个接受任何 JSON 对象的通用映射。
- **响应:**
  - 一个硬编码的 JSON 对象: `{"code": 1, "msg": "成功"}`

### 2. 创建移库任务 (存根)

- **URL:** `/api/ReceWms/CreateMoveTask`
- **HTTP 方法:** `POST`
- **描述:** 一个旨在创建内部仓库移库任务的占位符端点。目前，它只将请求体记录到控制台。
- **请求体:**
  - `carMsg` (Map<String, Object>): 一个接受任何 JSON 对象的通用映射。
- **响应:**
  - 一个硬编码的 JSON 对象: `{"code": 1, "msg": "成功"}`

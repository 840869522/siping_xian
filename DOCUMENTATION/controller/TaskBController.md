# TaskBController

`TaskBController` 是一个 Spring REST 控制器，用于管理“B库”（料箱库）的任务，这似乎是一个用于料箱或纸箱的自动化系统。它协调着广泛的活动，包括入库/出库移动、分拣机任务，以及通过工作站的电子标签（E-Tags）进行的复杂用户交互。

## API 端点

### 1. 创建分拣机任务

- **URL:** `/TaskB/TaskSortInsert`
- **HTTP 方法:** `POST`
- **描述:** 接收一个出库订单，并将其明细行分解为一系列 `TaskSort` 记录，这些记录是给分拣机的指令。
- **请求体:**
  - `outOrder`: 一个 `OutOrder` 对象。
- **响应:**
  - 一个指示结果的 `InterReturn` 对象。

### 2. 创建 B 库任务

- **URL:** `/TaskB/TaskBInsert`
- **HTTP 方法:** `POST`
- **描述:** 在 B 库中创建新任务的主要端点。它支持各种任务类型，如“入库”、“出库”和“回库”。它执行广泛的验证，以确保托盘尚未在任务中，库位有效，并且库位/托盘状态对于请求的操作是正确的。成功后，它会创建任务并冻结库位。
- **请求体:**
  - `taskB`: 一个包含任务详情的 `TaskB` 对象。
- **响应:**
  - 一个指示结果的 `InterReturn` 对象。

### 3. 获取 B 库任务

- **URL:** `/TaskB/GetTaskBByPage`
- **HTTP 方法:** `POST`
- **描述:** 使用分页和过滤器查询 B 库的任务。
- **请求体:**
  - `taskB`: 一个用于过滤的 `TaskB` 对象。
  - `pageNo` (int), `pageSize` (int)。
- **响应:**
  - 一个包含 `TaskB` 对象分页列表的 `InterReturn` 对象。

### 4. 更新 B 库任务状态

- **URL:** `/TaskB/UpdateTaskBStatusByTaskNo`
- **HTTP 方法:** `POST`
- **描述:** 手动更新特定 B 任务的状态。
- **请求体:**
  - `taskB`: 一个包含 `task_no` 和新 `status` 的 `TaskB` 对象。
- **响应:**
  - 一个指示结果的 `InterReturn` 对象。

### 5. 将拣货列表转换为 B 任务

- **URL:** `/TaskB/Pick2TaskB`
- **HTTP 方法:** `POST`
- **描述:** 一个强大的批量创建端点，它接收一个 `OutPick` 记录列表（由分配过程生成），按托盘/料箱对它们进行分组，找到每个料箱的当前位置，并创建一个排序的 `TaskB` 出库任务列表来检索它们。
- **请求体:**
  - 一个 `OutPick` 对象列表。
- **响应:**
  - 一个指示批量任务创建结果的 `InterReturn` 对象。

### 电子标签交互端点

当用户在工作站与电子标签交互时，WCS（仓库控制系统）会调用这些端点。

- **`/TaskZ/ETagOff`**: 电子标签按下的通用入口点。它判断是上层还是下层标签，并调用相应的方法。
- **`/TaskZ/ETagUp`**: 处理*上层*电子标签的按下，表示从源料箱中拣货。这个复杂的事务过程会：
  1. 完成当前的 `OutPick` 任务。
  2. 从源料箱中减少库存。
  3. 在目标（订单）料箱中增加库存。
  4. 检查是否还有来自同一源料箱的更多拣货。如果有，它会命令下一个物料的电子标签亮灯。
  5. 如果来自源料箱的所有拣货都已完成，它会解除料箱与电子标签的绑定，并为源料箱创建一个“回库”任务。
- **`/TaskZ/ETagDown`**: 处理*下层*电子标签的按下，表示目标（订单）料箱已满或完成，准备好被移走。
- **`/TaskZ/UnbindETag`**: 一个手动清除料箱和电子标签位置之间关联的工具。

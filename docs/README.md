# WMSMP 项目源码分析文档

## 概述

本项目是一个功能完善的仓库管理系统（WMS），其核心职责是管理仓库的入库、出库、库存、盘点等核心业务流程，并与各类自动化硬件进行深度集成。

本系列文档旨在对项目源码进行 file-by-file 级别的深度分析，阐述其模块划分、核心业务流程、关键技术实现和设计模式。

    *   *职责：负责AOP日志、配置、以及关键业务流程的自动化审计。*

*   **[模块二：库存管理模块](./02_inventory_management.md)**
    *   *职责：负责库存的精确追踪、管理和盘点，确保数据准确性。*
